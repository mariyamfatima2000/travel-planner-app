\# Travel Planner App



\## Problem

Solo travelers struggle to plan trips within a fixed budget and duration.



\## Target User

Budget-conscious solo travelers.



\## Core Features

1\. Search destinations by budget and days

2\. View destination cost breakdown

3\. Destination detail page

4\. Save trips locally

5\. Simple, no booking or payments



\## Tech Stack

\- React

\- JavaScript

\- HTML

\- CSS
